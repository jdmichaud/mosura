This is prereq (a) for landing the mainloop (prereq (b) = switchmulti dual-width selector = task #4). guardCalls-for-ram is INDEPENDENT of the mainloop and useful on its own (any global read across a call).

**THE GAP:** `guard_calls` (heritage.rs:1017) classifies effect only for `spc == reg` (SysV effect list) or aliased-`stack` (unknown_effect); a **ram** range hits `else { return }` → NO call guard. So a ram global's value across a call is read as its PRE-call version (or materialized as redundant pre-call writes under the S8-2 widening).

**GHIDRA MECHANISM (heritage.cc:1443 `guardCalls`, read precisely):** does NOT special-case ram — for EVERY heritaged range it does `effecttype = fc->hasEffect(transAddr,size)` (:1467) then branches:
- `unknown_effect` | `return_address` (:1511) → `indop = newIndirectOp(call, addr, size, 0)` (passthrough); `in(0)` + `out` setActiveHeritage; `write.push_back(out)`; **`if (holdind) out->setAddrForce()`** where `holdind = (fl & Varnode::addrtied)` (:1450); return_address → setReturnAddress.
- `killedbycall` (:1521) → newIndirectCreation.
- `unaffected` → no guard.
For a **ram global under a default/unknown FuncProto** (mosura's case — no populated scope/proto), `hasEffect` returns the default = **`unknown_effect`** → the passthrough INDIRECT branch fires. (The isOutputActive/characterizeAsOutput/isInputActive branches :1469-1509 are P6 prototype-recovery — NOT needed for the ram-global passthrough; document as the existing P6 gap.)

**Ghidra IR PROOF (revisit, oracle):** `r0x00100074:4(0x0010001c:5c) = EAX(0x00100017:8) [] i0x0010001c:14(free)` — the guardCalls passthrough INDIRECT threads the +10 result (EAX) across the call; the post-call narrow read is then `r0x00100074:2(:55) = SUB42(r0x00100074:4(:5c), #0)` = `(int2)iRam74` of the POST-call whole. mosura lacks the :5c INDIRECT → materializes `r74:4 = COPY u0x10018` + write-masked `r74:2 = SUBPIECE(u0x10018,#0)` and the post-call `+100` reads the PRE-call value → spurious `iRam74 = (int2)uVar1;`.

**THE mosura CHANGE (bounded, faithful):** in `guard_calls` (heritage.rs:1017) route a **ram/global range** to `effect::UNKNOWN_EFFECT` (mirroring the existing aliased-stack branch) so the EXISTING UNKNOWN_EFFECT arm (heritage.rs:1067: `new_indirect_op` passthrough, moved after call, addrForce if holdind) fires.
