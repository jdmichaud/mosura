# docs/product — mosura as a product

The productisation track: turning the port into a library with a C API, a session store, and a
CLI. The design and its executable plans; the prerequisites and P0 are landed, the rest in progress.

| file | what |
| --- | --- |
| [`architecture.md`](architecture.md) | the design: four crates, the operation/option/table spine, the flat session store (format spec), the CLI architecture decision (direct link, no state-owning daemon), migration of the examples and environment variables, staging plan, open decisions |
| [`mosura.h`](mosura.h) | first draft of the C API surface, to be generated by cbindgen from `mosura-capi` once it exists |
| [`plan-2026-09-05.md`](plan-2026-09-05.md) | the decisions of 2026-09-05 and the work packages that execute them: review items, environment-variable removal, a generic repository (subject profiles) |
| [`plan-wp7-2026-09-05.md`](plan-wp7-2026-09-05.md) | WP7, the product phases P0–P4: promote the emit driver into core (P0, landed), rename the core crate, `mosura-api` and the session store, the C ABI + binding + CLI, the rounds through the CLI, the dev tier — file-level, with gates; the owner's copy carries the machine paths |
